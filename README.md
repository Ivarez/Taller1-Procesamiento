# Taller: Procesamiento de Datos a Gran Escala

**Autor:** Iván Alvarez 

## Presentación de los Cuadernos
Este repositorio contiene la resolución estructurada, documentada y analítica de los ejercicios prácticos en Python.

## Estructura del Repositorio
* `01-Python-Cadenas.ipynb`: Manipulación de texto, indexación y métodos de limpieza.
* `02-Python-Tuplas.ipynb`: Estructuras inmutables, desempaquetado y eficiencia de memoria.
* `03-Python-Listas.ipynb`: Estructuras dinámicas, métodos de inserción, eliminación y mutabilidad.
* `04-Python-Conjuntos.ipynb`: Teoría de conjuntos aplicada al filtrado lógico y valores únicos.
* `05-Python-Diccionarios.ipynb`: Mapeo hash clave-valor para estructuración de datos.
* `06-Python-Condiciones.ipynb`: Control de flujo lógico y bifurcaciones algorítmicas.
* `07-Python-Bucles.ipynb`: Iteración sobre colecciones y optimización de ciclos de control.
* `08-Python-Funciones.ipynb`: Modularidad, encapsulamiento de lógica analítica y reutilización.
* `09_Python_Clases.ipynb`: Abstracción de entidades de datos mediante Programación Orientada a Objetos.
* `10-Practico_Bono_1.ipynb`: Ejercicios de integración complementarios.
