# Taller: Procesamiento de Datos a Gran Escala

**Autor:** Iván Alvarez 

## Presentación de los Cuadernos
Este repositorio contiene la resolución estructurada, documentada y analítica de los ejercicios prácticos en Python.

## Estructura del Repositorio
* `01-Python-Cadenas.ipynb`: Manipulación textual, indexación y extracción mediante slicing.
* `02-Python-Tuplas.ipynb`: Implementación de estructuras inmutables y de acceso posicional.
* `03-Python-Listas.ipynb`: Uso de arreglos mutables, métodos nativos de inserción y clonación.
* `04-Python-Conjuntos.ipynb`: Operaciones lógicas fundamentadas en la teoría de conjuntos y extracción de valores únicos.
* `05-Python-Diccionarios.ipynb`: Asignación y consulta optimizada mediante el mapeo clave-valor.
* `06-Python-Condiciones.ipynb`: Control algorítmico y bifurcaciones mediante operadores de evaluación y comparadores lógicos.
* `07-Python-Bucles.ipynb`: Rutinas de iteración para recorrer colecciones bajo condiciones fijas (`for`) y dinámicas (`while`).
* `08-Python-Funciones.ipynb`: Encapsulamiento del código analítico, modularidad y definición formal del ámbito de variables.
* `09_Python_Clases.ipynb`: Abstracción esquemática de la Programación Orientada a Objetos (POO), constructores y definición de métodos.
* `10-Practico_Bono_1.ipynb`: Ejercicios de integración lógica avanzada, resolución analítica y síntesis algorítmica.
